在手机上导入

若扫码后没有自动跳转游戏，请确认手机上已安装《皇室战争》。

添加卡组

设置

「清空我的卡组」只删除你自己创建的卡组（1v1 / 2v2），不会影响 HOT 卡组。

链接参数

默认沿用官方 / RoyaleAPI 的写法（l=Royals、tt=159000000），一般无需修改。

形态信息（觉醒 / 英雄 / 精英）

觉醒编码 1 是已验证的官方写法（slots 与 deck 逐位对应，1 = 觉醒）； 精英的编码目前没有公开资料，留空表示不写入链接（导入后需在游戏内手动设置）。 英雄卡是卡牌固有属性，不需要编码。

槽位规则（每个位置允许的形态）

位置★ 普通★ 觉醒★ 精英★ 英雄
默认：第 1 格可放觉醒；第 2 格可放精英 / 英雄；第 3 格为万能槽（觉醒 / 精英 / 英雄）；第 4–8 格只能放普通卡。可按你游戏里的实际情况修改。

卡组数据（保存在浏览器本地，不在 HTML 文件里）

上面是你当前浏览器里实际保存的卡组（localStorage cr_decks_v2），页面显示的以它为准，而不是文件里写死的示例。

登录账号

登录后，你的卡组、设置和主题会保存在云端，手机和电脑用同一个账号即可看到同一份数据。
不登录也能正常使用，数据只存在这台设备的浏览器里。
已登录：
「退出登录」只是不再在这台设备上同步，云端数据仍在。
「删除账号」会永久删掉云端全部卡组与账号本身，且无法恢复。
